# 我只在乎你

独立 AstrBot 插件。全天约每 50～70 分钟获得一次自主行动机会，根据当前人格、近期对话和"我会牢牢记住你"记忆，选择聊天、创作、工具行动或沉默。

## v1.13.10：「关于你」保留人物关系和原话

- 只自动记录明确的长期互动偏好及可核对的陪伴相关事实。保留来源原话，分清陪伴对象与其朋友、家人，不再自动扩写兴趣。
- 不把单个插件／项目的停用决定归为长期偏好；不删除历史聊天和已有条目。

## v1.13.9：「关于你」减少无关收录

- 自动收录限于明确的长期互动偏好和兴趣；临时请求、转述和聊天杂项不写入。
- 以实际用户原话为记录内容，不保留模型自行扩写的结论。不新增确认步骤，不删除旧记录，事实仍可手动添加。

## v1.13.8：陪伴工作台改版

- 「总览」首次打开时显示三步入门；已有对象时显示陪伴近况和快捷入口。
- 「设置」先显示 QQ 对象、平台提示与保存，其余项目移到「更多设置」。
- 「作品库」将浏览、管理与成果箱分开，保留媒体查看和原有操作；「行为与计划」新增三种计划类型的页内导览。
- 保留原有暖米白与墨黑配色，适配窄屏与键盘导航；不改变调度、权限或现有数据。

## v1.13.7：媒体作品保存与查看

- 作品详情可以直接播放本地 MP3、WAV、MP4 等常见格式；实际能否播放取决于浏览器和文件编码。
- 已取得的本地图片、音频和视频在发送前或收到成功工具回执时写入独立备份，校验成功才标记「已备份」。已有文件且仍可访问的旧投递媒体会在加载插件时补存；单文件备份上限 100 MB。
- 不会重生成或重发缺失媒体。ComfyUI 远程图片仍限于配置的成图接口，旧记录可以手工补存。

## v1.13.6：作品库展示

- 「作品库」默认显示创作成果；旧列表中的读取、校验等条目可在「查看引用资料」中找到。
- 相同内容的本地图片合为一张卡，展开可看各条来源；同名不同内容的正文仍单独展示。
- 列表显示来源、可用日期和已知的草稿／完稿状态，区分本地文件缺失、仅远程引用与内嵌正文。
- 不改旧索引、原文件、作品数量上限或分页策略。

## v1.13.5：主动投递和后台执行修复

- 改进暂停和投递结果处理，防止早报、主动轮互相打断或重复发送已经提交的内容。
- 规范 QQ 私聊路由；发送前只用同一会话的真实近期用户消息判断用户状态，不把自主任务描述当作用户发言。
- 过期约定不再占满名额或绕过安静时段；自动聊天整理不会改动手动固定的记忆。
- 自己约好的开口优先于后台任务；后台阶段单独计工具额度，已核验成果与草稿、部分完成不混淆。
- 本插件的专用后台不回显 DSH API 密钥，留空保留原值；从作品目录移除项目保留原文件且不再自动重新收录。

## v1.13.4：项目、后台任务与完成记录

- **持续项目**保存目标、进展和下一步，由日常主动轮择机推进。进行中与暂停合计最多 5 项；完成或取消后进入「项目历史」，不占栏位。
- **长期任务**是在独立上下文和工作区里分阶段执行的后台作业，适合有明确验收标准的交付，不会主动发消息。卡住、过程被打断或结果不确定时，核对后再恢复。
- **暂停**保留进度和回执；**取消**停止后续执行并保留记录；**删除**移除记录，不删除已保存的文件。三者都不能保证撤回已经提交到外部服务的操作。
- 普通聊天、主动轮和聊天后的计划整理都能参考完成记录与保存回执。保存了草稿不等于整项已完成，已完成也不等于已发送。

## v1.13.3：主动聊天按现实时间走

- 主动聊天以 Bot 服务器的本地时间为准。保留人格和聊天口吻，但旧对白不等于正在发生的情景。请确认 Bot 主机或容器的时区正确。
- 后台聊天草稿跨日或遇到用户新消息后不再自动补发；这不影响已保存的作品。
- 早报不把聊天台词当作真实经历，没有值得报告的内容就跳过。完全不想收到早报，可以关闭 `morning_report_enabled`。

## 适配自动学习插件（v1.13）

v1.13 修复与 `astrbot_plugin_task_skills`（自动化 skills 学习）的集成链路：

1. **长期任务可学习**：后台长期任务的 `tool_loop_agent` 现在传入 `agent_hooks=self.notification_hooks`，下游技能学习插件能采集到完整的工具证据；任务文本用任务目标替代占位的"自主心跳"。
2. **总结质量提升**：主动轮钩子把控制 JSON 改写成只说给用户的台词，模型自己记录的任务结果（summary 字段）留在控制原文里；学习优先使用 summary，其次台词，最后退回原文。
3. **DSH 工具成功回执误判修复**：`autonomous_dsh_cli` 的成功回执固定携带空 `"error"` 键，旧正则匹配失败词导致每次成功调用都被记成失败证据；新代码解析结构化 JSON 以状态字段为准。
4. **未完成步骤过滤**：长期任务的 continue/waiting 阶段不进入技能库，只有 completed 才允许学习。

## 使用

### 自己约定下次开口时间（v1.11）

bot 可以在自主判断、行动结束或普通聊天整理时输出 `next_speak_minutes`（5～1440 分钟，配 `next_speak_reason`），自己决定下次什么时候开口。这不同于 `next_check_minutes`（下次只做判断，仍可能沉默）：开口约定到点会专门唤醒一次，提示词明确标注"已到你自己约定的开口时间"，本轮默认开口说话而不是沉默；确实无话可说时模型仍可沉默，但需说明原因。
