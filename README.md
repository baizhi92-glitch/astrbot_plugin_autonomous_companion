# 我只在乎你

「我只在乎你」是一个 **AstrBot QQ 私聊陪伴插件**。它会参考当前人格和近期对话，定期判断要不要找你说话、做点事，或者保持安静。**一次判断不等于一条消息**；它也可以先把作品存起来，等你想看时再打开。

适用于 AstrBot **4.28.1 及以上**。可独立运行，不必先安装记忆或陪伴插件。当前版本：**v1.13.12** · [本次更新](CHANGELOG.md#v11312--修复作品库音频预览)

## 三步开始

1. 在 AstrBot 插件管理中用 [GitHub 仓库地址](https://github.com/baizhi92-glitch/astrbot_plugin_autonomous_companion) 安装插件，加载后刷新管理页，在侧栏打开 **「我只在乎你」**。面板沿用 AstrBot 登录，不用另开端口。
2. 到 **设置** 填写要陪伴的 QQ 号并保存。只有一个 OneBot 实例时可自动识别；多个实例时请选对平台。也可以在目标私聊发送 `/自主 开启`。
3. 回到 **总览** 看下次判断和当前状态；需要确认连接时，可在私聊用 `/自主 状态` 或 `/自主 预览`。想关闭这个私聊的自主心跳，用 `/自主 关闭`。

## 能做什么

| 想做的事 | 功能和入口 |
| --- | --- |
| 有一点主动陪伴，但不想被定时打扰 | **总览 / 设置**：默认基础判断间隔是 60 分钟、随机浮动 10 分钟，实际节奏可以自适应。可以按对象暂停、设置免打扰和查看用量。 |
| 记住下次要说什么、想把事情做完 | **行为与计划**：一次性的开口约定、择机推进的持续项目，以及在独立上下文和工作区执行的长期任务。长期任务不主动发消息，遇到卡点可核对后再恢复。 |
| 先看作品，再决定要不要发 | **作品库**：浏览已保存的正文、图片和音视频；可加入**成果箱**再决定是否发送。支持按系列、标题或路径搜索，可恢复草稿历史版本、给章节定稿或合订。成果箱是待处理清单，不是所有作品；里面空了也不代表没有作品。 |
| 让陪伴更贴近真实聊天 | **行为与计划 → 关于你**：从实际用户原话记录明确的长期互动偏好和可核对的陪伴相关事实，区分你与朋友、家人，不把转述或临时决定当成长久偏好。也可以手动维护。 |
| 看它做了什么、为什么没发 | 在工作台查看活动与计划进度；需要排查时可在私聊用 `/自主 诊断` 导出诊断。 |

## 几个容易忽略的小特色

- **自己约下次开口，而不是只设闹钟。**「到点开口」和「到点再判断」是两回事；多个开口约定能排队，过期的约定不会挤占名额或绕过免打扰。
- **早报有事才说。** 默认最早按 Bot 主机或容器的本地时间 **08:00** 判断是否发送；有真实成果、卡点或待处理事项才汇报。想完全关闭，可关闭 `morning_report_enabled`。
- **同一张图不反复刷屏。** 作品库会合并内容相同的本地图片，仍可展开查看来源；同名但内容不同的正文不会合并。常见本地音视频可在详情中预览，具体取决于浏览器和文件编码。
- **已保存、已完成、已发送分开记。** 草稿不会被当成交付完成；从目录移除作品也不会删除原文件。取得的本地图片、音频、视频可独立备份，单文件上限 100 MB。

## 使用前知道这几件事

- 记忆与其他陪伴插件是可选联动；可用时遵循已有的会话和记忆范围，不可用时仍能用近期对话运行。
- 主动判断、聊天后整理和后台任务可能增加模型调用；可在 **设置 → 更多设置** 按需调整节奏和额度。本机 DSH 执行默认关闭，不是基本陪伴的前置条件。
- 暂停保留进度，取消停止后续执行，删除移除记录；都不能保证撤回已经提交给外部服务的操作。
