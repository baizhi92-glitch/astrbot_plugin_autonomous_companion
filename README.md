# 我只在乎你

独立 AstrBot 插件。全天约每 50～70 分钟获得一次自主行动机会，根据当前人格、近期对话和"我会牢牢记住你"记忆，选择聊天、创作、工具行动或沉默。

## 适配自动学习插件（v1.13）

v1.13 修复与 `astrbot_plugin_task_skills`（自动化 skills 学习）的集成链路：

1. **长期任务可学习**：后台长期任务的 `tool_loop_agent` 现在传入 `agent_hooks=self.notification_hooks`，下游技能学习插件能采集到完整的工具证据；任务文本用任务目标替代占位的"自主心跳"。
2. **总结质量提升**：主动轮钩子把控制 JSON 改写成只说给用户的台词，模型自己记录的任务结果（summary 字段）留在控制原文里；学习优先使用 summary，其次台词，最后退回原文。
3. **DSH 工具成功回执误判修复**：`autonomous_dsh_cli` 的成功回执固定携带空 `"error"` 键，旧正则匹配失败词导致每次成功调用都被记成失败证据；新代码解析结构化 JSON 以状态字段为准。
4. **未完成步骤过滤**：长期任务的 continue/waiting 阶段不进入技能库，只有 completed 才允许学习。

诊断日志显示"版本 1.2.0；诊断 companion-bridge-v2"（task_skills），companion 为 1.13.0。

## 使用

### 自己约定下次开口时间（v1.11）

bot 可以在自主判断、行动结束或普通聊天整理时输出 `next_speak_minutes`（5～1440 分钟，配 `next_speak_reason`），自己决定下次什么时候开口。这不同于 `next_check_minutes`（下次只做判断，仍可能沉默）：开口约定到点会专门唤醒一次，提示词明确标注"已到你自己约定的开口时间"，本轮默认开口说话而不是沉默；确实无话可说时模型仍可沉默，但需说明原因。
